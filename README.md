# 考公工作台

一个仿照截图风格的移动端备考工作台网页，可添加到手机桌面作为 PWA 使用。

## 功能

- **备考总规划看板**：今日任务统计、完成率、阶段路线
- **每日任务中心**：任务清单、完成率环形图、按分类添加任务
- **专项刷题题库**：6 大模块进度、模拟刷题、错题本入口
- **全真模考专区**：模考成绩列表与成绩趋势柱状图
- **侧边栏导航**：7 个模块入口，当前页面高亮
- **考试倒计时**：可自定义考试日期
- **数据持久化**：使用浏览器 localStorage，刷新不丢失
- **PWA 支持**：可“添加到主屏幕”，像原生 App 一样使用

## 如何使用

### 1. 直接打开

用浏览器打开 `index.html` 即可使用。

### 2. 部署到手机桌面（PWA）

**Android（Chrome）**
1. 用 Chrome 打开网页。
2. 点击右下角/右上角菜单 → **添加到主屏幕**。
3. 确认添加，桌面会出现“考公工作台”图标。

**iPhone（Safari）**
1. 用 Safari 打开网页。
2. 点击底部分享按钮（<span style="font-size:1.2em">⬆️</span>）。
3. 选择 **添加到主屏幕** → 添加。

### 3. 备份与恢复

进入“备考工具箱”：
- **导出数据**：下载 JSON 备份文件。
- **导入数据**：粘贴 JSON 数据恢复。
- **重置数据**：清空所有本地记录。
